# 🚀 SmartHire AI – Resume Analyzer

SmartHire AI is a browser-based resume analyzer
built using HTML, CSS and JavaScript.

## ✨ Features

- PDF Resume Upload
- Estimated ATS Score
- Automatic Skill Detection
- Job Role Matching
- Missing Skills Detection
- Resume Section Analysis
- Smart Improvement Suggestions
- Downloadable Analysis Report
- Analysis History
- LocalStorage Integration
- Responsive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PDF.js
- LocalStorage API

## ⚙️ How to Run

1. Clone the repository.

2. Open the folder in VS Code.

3. Install Live Server extension.

4. Right-click index.html.

5. Select Open with Live Server.

6. Start analyzing your resume!

- Frontend Developer
- Full Stack Developer
- Data Analyst
- AI/ML Engineer

## 🔒 Privacy

Resume text is processed in the browser.
Only analysis summaries are stored in LocalStorage.
Original resume files are not uploaded to a server.

## ⚠️ Disclaimer

The ATS score is a rule-based educational estimate.
It is not an official score from an employer's ATS.
